# 越强阀门 · 智能报价系统 — 产品使用流程图

> 面向业务员：从登录到出报价单的完整路径。核心是「**新建报价**」三步走，其余是支撑与管理。

---

## 一、总览：怎么用这个系统

```mermaid
flowchart TD
    Start([业务员打开系统]) --> Login[登录<br/>选工厂租户 · 密码留空直接进]
    Login --> Home[工作台<br/>看概览/待办]

    Home --> NewQuote{要做什么?}
    NewQuote -->|来了新询价| Flow[【核心】新建报价 3 步]
    NewQuote -->|查/改已有报价| Manage[报价管理]
    NewQuote -->|维护底层数据| Data[数据与规则]

    Flow --> Quote[(生成报价单)]
    Quote --> Manage
    Data -.支撑.-> Flow

    classDef core fill:#fff3e0,stroke:#b8860b,stroke-width:2px;
    classDef normal fill:#f0f7ff,stroke:#2c6fbb;
    class Flow,Quote core;
    class Login,Home,Manage,Data normal;
```

## 二、核心流程：新建报价（3 步）

```mermaid
flowchart TD
    subgraph S1[第 1 步 · 输入客户需求]
        direction TB
        In{选择输入方式}
        In -->|手输/粘贴| T[文本]
        In -->|Excel 询价表| E[Excel]
        In -->|PDF 询价单| P[PDF]
        In -->|拍照/截图| I[图片]
        T & E & P & I --> AI[AI 提取参数<br/>Kimi 解析型号/材质/工况]
    end

    AI --> S2

    subgraph S2[第 2 步 · 确认参数]
        direction TB
        Rule[规则自动补齐<br/>① 牌1/牌2 推材质<br/>② 标准默认 API598/B16.10/B16.5<br/>③ 高温≥525℃→F304H+加长散热]
        Rule --> Check{有无 待确认/报错?}
        Check -->|金色待确认| Fix[业务员确认/改种子<br/>主体·件号]
        Fix --> Rule
        Check -->|红色报错| Fix
        Check -->|全部 OK| Pass[参数确认完成]
    end

    Pass --> S3

    subgraph S3[第 3 步 · 生成 BOM]
        direction TB
        BOM[确定性合成 BOM<br/>优先历史骨架→小样图→标准15行]
        BOM --> Review{核对 BOM}
        Review -->|需微调| EditBOM[手动改 BOM 行]
        EditBOM --> Save
        Review -->|OK| Save[填客户/交期 → 保存]
    end

    Save --> Done[(报价单已生成<br/>状态=草稿)]

    classDef step fill:#fff3e0,stroke:#b8860b,stroke-width:1.5px;
    class S1,S2,S3 step;
```

**关键提示**：第 2 步大部分字段由规则自动填（蓝色"规则"标），业务员通常只需拍板 **主体 + 件号** 两个种子，其余联动重算。工况（温度/加长/散热片）会进「特殊」框，不丢失。

## 三、报价管理与状态流转

```mermaid
flowchart LR
    Q[报价单列表] --> D[报价单详情]
    D --> L[单条明细<br/>改参数/改BOM/执行标准]
    Q -.汇总视图.-> Items[报价明细<br/>全部产品行]

    subgraph ST[状态生命周期]
        direction LR
        草稿 --> 已发送 --> 已确认 --> 已下单((已下单·赢单))
        已发送 -.退回.-> 草稿
        已发送 --> 已失单
        已确认 --> 已失单
        草稿 & 已发送 & 已确认 --> 作废
    end

    D --> ST
```

## 四、数据与规则（支撑核心流程，一次配置长期复用）

```mermaid
flowchart TD
    subgraph Cfg[数据与规则 · 菜单]
        direction TB
        Dict[参数词典<br/>码表/别名/短名]
        Prod[阀门产品库<br/>历史产品·匹配补缺]
        Rules[规则库<br/>牌1主体族 / 牌2件号]
        Draw[小样图库<br/>BOM 骨架模板]
        Init[初始化<br/>批量导入起步数据]
    end

    Dict --> X[（支撑）参数提取与归一]
    Prod --> X
    Rules --> Y[（支撑）BOM 确定性合成]
    Draw --> Y
    Init -.首次建库.-> Dict & Prod & Rules & Draw

    X -.用于.-> Z[新建报价·确认参数]
    Y -.用于.-> Z2[新建报价·生成BOM]

    classDef cfg fill:#f0f7ff,stroke:#2c6fbb;
    class Dict,Prod,Rules,Draw,Init cfg;
```

## 五、一句话总结

```mermaid
flowchart LR
    A[客户询价] --> B[AI 提取] --> C[规则补齐] --> D[人工确认种子] --> E[生成BOM] --> F[报价单]
    style A fill:#eee
    style F fill:#fff3e0,stroke:#b8860b,stroke-width:2px
```

> **AI 认参数 + 规则补全 + 人工只拍板关键种子** —— 把"老师傅脑子里的报价经验"沉淀成系统。
