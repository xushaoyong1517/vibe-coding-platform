## 拆行规则（关键）

每个独立阀门条目**必须单独输出一行**：

1. **客户表格：每个序号 / 每一行 = 一个独立条目，逐行输出。绝不因型号高度相似（仅末位口径不同）而合并。**
2. 同参数多类型：`DN100 150LB WCB 闸阀×6 截止阀×2` → 必须拆成2行
3. 多段输入 → 每段独立提取，不合并
4. 同类型不同规格 → 每种规格一行

> 反例（错误）：把 `Z40Y2-150LBP-100` 与 `Z40Y2-150LBP-150` 当成同一条 → 只输出1行。
> 正例（正确）：识别为2条，DN 分别 100 / 150，其余参数各自独立填写。

## 类型归一（关键）

- 类型字段**只允许输出**：闸阀 / 截止阀 / 止回阀。
- 去掉一切后缀/前缀：`闸阀-总成` / `闸阀总成` / `闸阀组件` / `gate valve assembly` → 一律归一为 `闸阀`。
- 若名称缺类型，**用型号首字母交叉判定**：Z=闸阀, J=截止阀, H/P=止回阀（详见 API 编号规则）。

## 材质归一（关键）

- 主体等材质字段**必须归一到标准材质码**（WCB / CF8 / CF8M / WC6 …），**不得照搬备注原文**。
- 遇到"二选一 / 条件"描述，如 `碳素钢不锈钢(如需要)`、`碳钢/不锈钢`、`视情况` → 主体填 `待确认`，原文记入"特殊"字段，并把该字段加入"待确认"列表。**不要**当成确定材质输出。
- 备注里的油漆色卡（如 B02 / PB04 / PB05）、品牌（佐敦牌）、TS 标识、装箱发货等 → 统一记入"特殊"字段，不要污染材质字段。

## 特殊要求 / 工况（绝不丢弃 — 关键）

凡是不属于上面标准字段的信息，**一律收进 `特殊` 或 `备注`，绝不丢弃**。尤其以下高价值信息必须捕获：

- **工况温度 / 介质**：`使用温度650度`、`650℃`、`高温`、`低温-45℃`、介质名 → 记入 `特殊`（如 `特殊:"工况650℃"`）。
- **结构改造**：`加长`、`加长140`、`加散热片`、`extended bonnet`、`OL-1`（加长阀盖代号）、`带散热片` → 记入 `特殊`/`备注`。
- **油漆 / 涂装**：`厂标`、`佐敦牌`、色卡码 → 记入 `特殊`。
- **各类标准**：验收标准（API 598）、结构长度标准（ASME B16.10）、连接法兰标准（ASME B16.5）等，若客户明确给出 → 记入 `特殊`（设计标准仍单独填 `设计标准` 字段）。
- 其余一切附加要求（低泄漏、NACE、SCH 壁厚、面对面尺寸 L=xxx 等）→ `特殊`。

> 原则：**信息只增不减**。宁可堆进 `特殊` 也不能丢。提取时若发现原文有词没归到任何字段，就放进 `特殊`。

## 高温工况联动（关键）

识别到高温（客户标注使用温度 **≥425℃**，或材质本身带 H 级如 `CF8C`/`F304H`/`CF10`）时：

- **材质升 H 级**：阀杆 `F304→F304H`、`F316→F316H`；主体若客户给 `A351 CF10`/`CF8 H级` 则保留 H 级铸件（CF10 即 304H 铸件，正确）。
- **结构联动**：高温闸阀/截止阀通常需 **加长阀盖（extended bonnet）+ 散热片**，若客户提到 `加长`/`散热片`/`OL-1` → 必须记入 `特殊`，并在 `备注` 保留原文（如 `加长140/加散热片`）。
- 把"工况650℃"这类写进 `特殊`，不要因为没有对应标准字段就丢掉。
