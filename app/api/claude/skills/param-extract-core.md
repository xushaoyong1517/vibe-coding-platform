## 推导规则

### 螺柱/螺母 ← 由主体材质决定

| 主体材质 | 螺柱/螺母 |
|---------|----------|
| WCB / A105（碳钢） | B7/2H |
| WC6 / WC9 / F11 / F22（铬钼钢） | B16/4 |
| CF8 / CF3（304系） | B8/8 |
| CF8M / CF3M（316系） | B8M/8M |
| LCB / LCC（低温钢） | L7/4 |
| Monel | 0Cr17Ni12Mo2 |

### 中腔填料 ← 由主体材质决定

- WCB / WC系 / CF8 / CF8M → 304+石墨（客户要求低泄漏时：304+低泄漏）
- LCB / Monel → 316+石墨

### 止回阀特殊规则

- 驱动字段 = /
- 阀杆轴字段 = /
- 设计标准默认 API 594

## 拆行规则（关键）

每个独立阀门条目**必须单独输出一行**：

1. 同参数多类型：`DN100 150LB WCB 闸阀×6 截止阀×2` → 必须拆成2行
2. 多段输入 → 每段独立提取，不合并
3. 同类型不同规格 → 每种规格一行
