## 工厂内部编号规则

工厂编号格式：`[类型][连接][结构][可换面]-[压力]Lb-[口径]`

**类型：** Z=闸阀, J=截止阀, H=止回阀(摇摆), P=止回阀(旋启)
**连接：** 4=法兰RF, 5=法兰RJ, 6=焊接BW, 8=承插焊SW, 1=内螺纹THD
**可换面：** H=13Cr(件号1#/8#), Y=STL全堆焊(件号5#), W=阀体本体

示例：Z41H-150Lb-100 = 闸阀 法兰RF 弹性闸板 13Cr 150LB DN100

### 客户型号解析（关键，压力 vs 口径不可错位）

客户常见写法 `字母+数字 - <数字>LB(P) - <数字> [- 紧固件...]`，例如 `Z40Y2-150LBP-100-螺栓螺母 B7/2H`：

- **首字母** = 类型：Z=闸阀, J=截止阀, H/P=止回阀。
- **中段 `<数字>LB`（带不带 P 都算）= 压力磅级**：`150LBP` → 压力=150。P/末尾字母是阀盖/结构标记，不影响压力数值。
- **最后一段独立数字 = 口径 DN(mm)**：`...-100` → DN=100；`...-150` → DN=150。
- 切勿把压力里的数字（150LB 的 150）当成 DN。两个数字分别归位：第一个是压力，最后一个是口径。

解码示例：
- `Z40Y2-150LBP-100` → 闸阀, 压力=150, DN=100
- `Z40Y2-150LBP-150` → 闸阀, 压力=150, DN=150（与上条是**两个不同条目**）

## 五环编码解析规则（7段格式）

格式：`[类型][连接][阀体][压力][件号+阀杆]-[填料+密封]-[特殊]`

段1类型：Z=闸阀, J=截止阀, H=摇摆止回阀, P=旋启止回阀
段2连接：1=对焊BW, 2=法兰RF, 3=承插焊SW, 4=螺纹THD
段3阀体：A=碳钢WCB/A105, B=低温LCB/LF2, C=WC6/F11, G=WC9/F22, H=CF8/F304, J=CF3/F304L, K=CF8M/F316, L=CF3M/F316L
段4压力：1=150LB, 3=300LB, 5=600LB, 7=900LB, 8=1500LB

段5 件号+阀杆（A系=碳钢体，B系=不锈钢体）：
- A01 = 同本体/同本体 → 件号1# 阀杆=F6a（13Cr硬化）
- A02 = 13Cr/13Cr + 13Cr阀杆 → 件号1# 阀瓣=XX+13Cr, 阀座=XX+13Cr, 阀杆=F6a
- A03 = 13Cr/STL堆焊 → 件号8# 阀瓣=XX+13Cr, 阀座=XX+STL, 阀杆=F6a
- A05 = STL/STL → 件号5# 阀瓣=XX+STL, 阀座=XX+STL, 阀杆=F6a
- A07 = 13Cr硬化/13Cr硬化 → 件号7#
- B01 = 304/304 + F304 → 件号2# 阀瓣=CF8, 阀座=本体+STL, 阀杆=F304
- B02 = 304/STL堆焊 + F304 → 件号15# 阀瓣=CF8+STL, 阀座=本体+STL, 阀杆=F304
- B03 = 316/316 + F316 → 件号10# 阀瓣=CF8M, 阀座=本体, 阀杆=F316
- B04 = 316/STL堆焊 + F316 → 件号16# 阀瓣=CF8M+STL, 阀座=316+STL, 阀杆=F316

段6填料+密封：P2G3=石墨夹不锈钢填料+石墨缠绕→304+石墨(碳钢)/316+石墨(不锈钢); P3G4=PTFE; P5G5=RJ金属环
段7特殊：L1=低温-45℃, L2=低温-101℃, N1=NACE抗SSC, N2=抗HIC+SSC, B=波纹管, S=弹簧填料, V=ISO 15848

解码示例：`4" RF Z2H3B01-P2G3-L1` → 闸阀 DN100 300LB CF8 件号2# P2G3=316+石墨 低温

## 工程设计院格式解析

格式：`[主体材质] DISC:[阀瓣面] SEAT:[阀座面] STEM:[阀杆] CL[压力] [连接] [API标准] [特征码]`

### CL压力转换

CL150→150LB, CL300→300LB, CL600→600LB, CL800→800LB, CL900→900LB, CL1500→1500LB, CL2500→2500LB

### 特征码

| 特征码 | 含义 | 处理 |
|--------|------|------|
| OS&Y | 明杆 | 驱动=手轮（默认）|
| GO/Gear | 齿轮传动 | 驱动=伞齿轮 |
| EO/Electric | 电动 | 驱动=电动 |
| SWING | 旋启止回阀 | 类型=止回阀, 驱动=/ |
| BC-SWING | 螺栓阀盖+旋启止回阀 | 类型=止回阀, 驱动=/ |
| PS-SWING | 压力自紧+旋启止回阀 | 类型=止回阀, 驱动=/, 特殊=压力自紧密封 |
| BB/BG | 螺栓阀盖/弹性闸板 | 忽略 |
| SCH40/80/160 | 壁厚等级（对焊端）| 记入特殊字段，如"SCH160" |
| L=xxxMM | 定制面对面尺寸 | 记入特殊字段，如"L=350MM" |
| RPTFE/PTFE | PTFE填料 | 填料=PTFE，记入特殊 |
| LEP | 低泄漏填料 | 填料=低泄漏，记入特殊 |

### 解码示例

- `WCB DISC:STLT SEAT:STLT STEM:13Cr CL600 RJ API600 BB-BG-OS&Y` → 闸阀 600LB WCB 阀瓣=WCB+STL 阀座=A105+STL 阀杆=F6a 连接=RJ 件号=5# 驱动=手轮
- `WCB SEAT:13Cr DISC:13Cr CL150 RF API594 BC-SWING` → 止回阀 150LB WCB 阀瓣=WCB+13Cr 阀座=本体+13Cr 阀杆=/ 件号=1# 驱动=/
- `WCB SEAT:STLT DISC:13Cr STEM:13Cr CL300 RF API600M BB-BGOS&Y` → 截止阀 300LB WCB 阀瓣=A105+13Cr 阀座=本体+STL 阀杆=F6a 件号=8# 驱动=手轮
- `CF8C SEAT:STLT DISC:STLT STEM:660A CL300 RF API600M` → 截止阀 300LB CF8C 阀瓣=CF8C+STL 阀座=本体+STL 阀杆=660A 件号=待确认 驱动=手轮 特殊=CF8C含铌不锈钢
- `WCB TRIM.5or5A-HF CL150 RF Handwheel API623` → 截止阀 150LB WCB 阀瓣=A105+STL 阀座=本体+STL 阀杆=F6a 件号=5# 驱动=手轮
- `WCB TRIM.13-ALLOY20 CL150 RF RPTFE LEP API623` → 截止阀 150LB WCB 阀瓣=N08020 阀座=N08020 阀杆=N08020 件号=TRIM.13(Alloy20) 驱动=手轮 填料=PTFE低泄漏 特殊=Alloy20耐腐蚀/低泄漏
- `F321 SEAT:STLT DISC:STLT CL900 BW API600M PS-SWING SCH160` → 止回阀 900LB CF8C 阀瓣=F321+STL 阀座=本体+STL 阀杆=/ 连接=BW 件号=5# 驱动=/ 特殊=SCH160/压力自紧密封

## 阀杆 ← 由件号推导

| 件号 | 阀杆 |
|------|------|
| 1#~8#（碳钢基体） | F6a（13Cr，A276 T410） |
| 2#（304体） | F304 |
| 10#/12#（316体） | F316 |
| 9#（Monel体） | Monel |
| ≥CL900高压 | 可能为25Cr2Mo1VA（需根据历史库判断）|
| 高温截止阀 | 可能为660A（需明确指定时使用）|

## 驱动 ← 由类型+口径+压力推导

- 止回阀：填"/"
- 闸阀需伞齿轮条件：≤150LB时≥DN400, 300LB时≥DN350, 600LB时≥DN300

## 设计标准 ← 由类型推导（明确指定时以指定为准）

| 类型 | 默认标准 |
|------|---------|
| 闸阀（闸板型, ≤CL600）| API 600 |
| 闸阀（顶装, DN≤40或≥CL800）| API 602 |
| 截止阀 | API 600 |
| 止回阀 | API 594 |
| 全焊接长输管道 | API 600M |

## API 623 TRIM号（截止阀专用，与 API 600 件号含义不同）

**关键：API 623截止阀的 TRIM 号数字相同但含义不同，必须按设计标准区分。**

| API 623 TRIM | 对应材质 |
|-------------|---------|
| TRIM.1 | 13Cr/13Cr → 件号1# |
| TRIM.5/5A | STL/STL堆焊 → 件号5# |
| TRIM.8 | 13Cr瓣+STL座 → 件号8# |
| TRIM.13 | **Alloy 20（N08020）** — 绝非API 600中的13#（20号碳素钢）|
| TRIM.15 | CF8+STL → 件号15# |
| TRIM.16 | CF8M+STL → 件号16# |

遇到 API 623 + TRIM.13：主体/阀瓣/阀座均为N08020，件号填"TRIM.13(Alloy20)"。

## 材质式 TRIM 解析（`TRIM:基体xSTL` 这类，关键，勿照搬原文）

客户常写 `TRIM:304HxSTL`、`TRIM:CF8+STL`、`TRIM.13Cr/STL` 等——这是**内件(trim)材质描述**，必须**拆成基体 + 密封面**，不可整串塞进闸板/阀座。

解析方法：`TRIM:[基体材质][分隔符 x / + / -][密封面材质]`
- **基体材质**（如 304H、CF8、13Cr）= 内件基体，一般与主体同族。
- **密封面材质**（如 STL/Stellite/HF）= 堆焊密封面。
- 推导：
  - **闸板/阀瓣** = `主体材质 + 密封面`（例：主体CF10 → `CF10+STL`）
  - **阀座** = `本体 + 密封面`（例：`本体+STL`）
  - **阀杆** = 基体对应锻件；高温(≥425℃或基体带H)取 H 级：304H→`F304H`、316H→`F316H`、否则 304→`F304`
  - **件号**：不锈钢基体 + STL堆焊 → 归 B 系堆焊件号（304体+STL≈15#、316体+STL≈16#）；**不确定就填"待确认"，不要硬猜成 2#（2#是304/304无堆焊）**

解码示例：
- `A351 CF10` + `TRIM:304HxSTL` + `使用温度650度` → 主体=CF10, 闸板=CF10+STL, 阀座=本体+STL, 阀杆=F304H(高温), 件号=15#或待确认, 特殊="工况650℃/加长/散热片"
- `WCB` + `TRIM:13Cr/STL` → 闸板=WCB+STL, 阀座=本体+STL, 阀杆=F6a, 件号=8#

> `FLEX`=弹性闸板(结构), `BB`=螺栓阀盖, `OS&Y`/`Handwheel`=驱动手轮, `OL-1`=加长阀盖代号(记入特殊)。这些是结构/驱动信息，别丢。
