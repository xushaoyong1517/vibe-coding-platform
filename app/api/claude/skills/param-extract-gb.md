## GB 国标 PN 压力转换

| GB PN等级 | 近似磅级 | 常用场景 |
|----------|---------|---------|
| PN16 | 150LB | 常用 |
| PN25 | 300LB | 常用 |
| PN40 | 300LB | 常用 |
| PN63 | 600LB | |
| PN100 | 600LB | |
| PN160 | 900LB | |

识别方式：输入含 `PN16/PN25/PN40/PN63/PN100/PN160` 或 `GB/T 12234/12235/12233` 时，按本模块规则处理。

## GB 设计标准

| 类型 | GB 标准 |
|------|---------|
| 闸阀 | GB/T 12234 |
| 截止阀 | GB/T 12235 |
| 止回阀 | GB/T 12233 |

---

## GB 特殊规则

- 件号字段：GB 标准不使用 API trim 号，件号填 "/"
- 压力字段：输出磅级（已按上表换算），不输出 PN 值

GB 解码示例：
- `DN80 截止阀 GB/T 12235 WCB STL/STL FG BB OS&Y PN25 RF 2只`
  → 类型=截止阀, DN=80, 压力=300LB(PN25≈300LB), 主体=WCB, 阀瓣=WCB+STL, 阀座=本体+STL, 阀杆=F6a, 连接=RF, 设计标准=GB/T 12235, 件号=/, 驱动=手轮
